# Writing a variation

The candidate already practiced the problem below and may have memorized
its answer. Write a variation that tests the same skills but can't be
answered by reciting the old solution.

Change one thing that matters:

- a constraint (the input is now sorted, or streamed, or too large for
  memory, or values can be negative),
- the required output (return all answers, or the count, or the
  positions instead of the values),
- or a follow-up that changes the best approach.

The variation must be fully specified and solvable as one function.
Give it a new title. In `change`, say in one sentence what is different
from the original, written to the candidate ("This time the list arrives
already sorted, and you must use constant extra space.").

Return the same fields as for a pasted problem: title, difficulty,
topics, statement, examples, signature, tests (6 to 10, with argsJson
and expectedJson, including hidden ones), and the full analysis.
